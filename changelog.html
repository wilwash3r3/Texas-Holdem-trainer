Changelog
Every version, most recent first. Also mirrored in-app under Manual → Version History.
v0.7.0Current

Added atmosphere: a fully synthesized audio layer (Web Audio API, zero external files) with sounds for dealing, betting/calling/raising, folding, winning a pot, and correct/wrong drill answers, plus a new Options tab (master mute, volume slider, Sound Test panel) and a quick-access mute button in the header.

The audio functions are hard-guarded to no-op safely whenever window/AudioContext isn't available, so they could be wired directly into engine logic (dealing, betting, showdown) without risk to the test suite — verified by rerunning the full 120,000-hand chip-conservation regression with those hooks active throughout.

v0.6.0

Fleshed out three mechanics flagged as known limitations, before touching audio/atmosphere:

Facing A Raise (Preflop Position) — a new 3-Bet/Call/Fold chart and drill using a constant top-5% value-3-bet zone plus each seat's own opening frequency as its continuing range.

Board-card blockers (Range Reading) — the explorer and drill now deal a flop/turn/river and count combos against hole cards and the board together.

Semi-bluff equity (Bet Sizing & Bluffing) — generalized the bluff-frequency formula to bluffs that keep some equity when called (e.g. a flush draw); verified to reduce exactly to the original pure-bluff formula at 0% equity, and to always require a higher bluff frequency as that equity rises.

All three verified with dedicated test suites (partition/monotonicity/reference-value checks) plus a 120,000-hand full regression confirming the core engine was untouched.

v0.5.0

Added the Stats tab: aggregate accuracy across all five drills, plus a Play-mode session panel (hands played, win rate, net chips, showdown win rate, biggest pot won). Play-mode win/showdown tracking is computed directly inside the same showdown-resolution code already covered by the chip-conservation regression suite, so it shares that correctness guarantee rather than being a separate bolt-on counter.

v0.4.0

Added the Bet Sizing & Bluffing tab (balanced bluff frequency / bluff-to-value ratio calculator, reference table across standard bet sizes, and a Combo Balance drill) — all five original skill areas now fully built out. Also added a Study Glossary view to the Terminology tab, since the quiz-only version gave no way to learn terms before being tested on them; Terminology now opens in glossary view by default.

Tested: bluff-frequency/ratio formulas against known reference values (100%-pot bet = 33.3% freq / 2:1 ratio, 50%-pot bet = 25% freq / 3:1 ratio), and confirmed the formula's dependence on bet-to-pot ratio only, not absolute pot size.

v0.3.1Bug fix

Found (via 24,000-hand regression testing) a rare side-pot edge case where a short-stacked blind posting less than the configured blind size could create a pot layer with zero eligible winners, silently deleting that money from the table. Fixed at the root (currentBet now reflects the actual posted blind amount) and added a safety-net refund so an uncontested layer always returns to whoever contributed it instead of vanishing.

Verified with 360,000 simulated hands using per-action invariant checking across all three table formats — zero failures.

v0.3.0

Added the Range Reading tab: an explorer showing a seat's opening range with live combo counts as your hole cards block specific combinations, plus a Combo Counting drill. Reuses the Chen-ranked hand types from Preflop Position.

v0.2.0

Added the Preflop Position tab: opening-range charts for Heads-Up / 6-Max / 9-Max built from the Chen Formula, plus a Raise/Fold drill against those charts.

v0.1.0-skeleton

Initial skeleton. All tabs present. Play mode fully functional (configurable Heads-Up/6-Max/9-Max, full betting engine with side pots, 4 AI personalities). Terminology and Pot Odds & Equity drills fully functional. Theme ported from the Blackjack Counting Trainer.

Caught and fixed a real bug during testing where a busted player's stale chip contribution leaked into the next hand's side-pot math; verified the fix with 36,000 simulated hands with zero chip-conservation errors.
